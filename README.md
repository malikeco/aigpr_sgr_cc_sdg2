# aigpr_sgr_cc_sdg2
Fragmented Geopolitics, Restricted Capital, and Zero Hunger: Global Evidence on SDG 2 Progress 
This repository is for the paper "Fragmented Geopolitics, Restricted Capital, and Zero Hunger: Global Evidence on SDG 2 Progress". It has two files: AIGPR_SGR_CC_SDG2.do and final-transformed_data.dta. The do file contains codes to reproduce the main result of this research.
